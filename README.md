# Silent Voice — A Silent Speech Recognition System

**Silent Voice** is a research project exploring **silent speech recognition using surface electromyography (sEMG)**.

The system aims to recognize speech-related muscle activity without requiring the user to produce audible speech. EMG signals captured from muscles involved in speech articulation are processed and passed through machine-learning models to classify intended words.

> **Research goal:** Investigate whether a low-cost, wearable sEMG system can provide reliable recognition of a limited vocabulary of silently articulated speech.

## 🔬 Research Components

### 1. Signal Acquisition

IRIS uses surface electromyography to measure electrical activity generated by muscles involved in speech.

The planned wearable system uses multiple electrode channels positioned around the neck and jaw region.

### 2. Signal Processing

The EMG signals undergo preprocessing before being provided to the recognition models.

Current processing experiments include:

* High-pass filtering
* Low-pass filtering
* 50 Hz notch filtering
* Windowing
* Signal normalization
* Artifact handling
* Time-frequency representations

### 3. Feature Extraction

Several representations are being investigated, including:

* MFCC-based features
* Time-frequency representations
* Raw EMG windows
* Spectral features

### 4. Machine Learning

Multiple model architectures are being evaluated.

Current experiments include:

* **MLP**
* **1D CNN**
* **2D CNN**
* Time-frequency CNN approaches

The project uses iterative prototypes to compare different preprocessing strategies, architectures, and training configurations.

## 📊 Datasets

IRIS currently experiments with multiple EMG speech datasets, including:

### Berkeley Silent Speech Dataset

Used for developing and evaluating silent-speech recognition models and investigating subject-independent generalization.

### EMG-UKA Trial Corpus

Used for signal-processing, phoneme-alignment, and speech-EMG experiments.

## 🧪 Experimental Approach

The project follows an iterative prototype-based research process.

```text
Prototype
    ↓
Train
    ↓
Validation
    ↓
Analyze errors
    ↓
Modify preprocessing / architecture
    ↓
New prototype
```

Rather than focusing only on the highest accuracy, the experiments investigate:

* Generalization across subjects
* Class imbalance
* Overfitting
* Signal representation
* Vocabulary size
* Model complexity
* Computational requirements
* Potential embedded deployment

## 🦾 Hardware

The eventual IRIS prototype is designed as a wearable neckband.

Planned hardware includes:

* sEMG electrodes
* EMG amplification circuitry
* ESP32
* Rechargeable battery
* Custom/3D-printed neckband enclosure

The hardware is being designed with **low-cost and embedded deployment** in mind.

## ⚠️ Research Status

Silent Voice is an ongoing experimental research project.

The current models should **not** be considered a clinically validated speech-assistance device. Results are experimental and are being used to investigate the feasibility and limitations of wearable sEMG-based silent speech recognition.
